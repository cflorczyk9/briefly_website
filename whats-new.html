Release notes

September 2026

Data

Orion portfolio data

Briefly can show Orion values in the client header, held-away accounts, and a line that reconciles Orion against the uploaded statements. The Clients list gets a Needs attention column, and Today shows portfolio alerts with an Add to Salesforce button. It turns on once a firm links Orion.

Security

Security hardening

Tasks that Ask creates now wait for your approval before they reach Salesforce. Uploads are checked for size and file type before the app opens them, connected inboxes must belong to your firm, and dependencies are updated. The full list is on the security page.

Schedules

A notice when schedules are paused

If your calendar connection stops working, the Schedules tab now says so. A banner explains that briefs and emails are paused, the next run reads Paused, and a Reconnect calendar button takes you to Integrations.

Schedules

Reports emailed after every scheduled run

When a scheduled run finishes, you get an email with the full report in the body and the same report attached as a PDF. You can copy up to three colleagues at your own firm, and replies come back to you. A Turn on morning briefs card sets up the first rule in one click.

Schedules

Schedule rules with cadences and client scopes

Rules now live in a table on the Agents tab, and you can keep several. A rule can run before every meeting, every week on a day and time, or every month. Each one covers all clients, only some, or all except some.

Agents

Firm view

Your CIO's notes become a dated timeline and one shared summary of what the firm thinks now, with the CIO's own words quoted behind each stance. The summary also appears as a Firm view section in briefs and client statuses, and it is cited in the market brief.

Release notes

August 2026

Agents

Star the agents you use most

Star your favorite agents on the Agents page and they stay at the front.

Agents

Market brief agent

The market brief reads the statements on file, then researches the web for the household's top positions, industry news, and analyst views. It also shows statement activity and the banks' published house views, and lists every web source in a numbered footer.

Branding

Your brand on every agent output

Your firm's logo and two colors now appear on every agent output, on screen, in the saved PDF, and when you copy the report into an email. You set them once in Preferences.

Ask

Searchable Ask history

Ask now opens a new chat each time, and past chats sit in a history panel you can search. A client filter narrows the list to one household.

Appearance

Dark mode

Choose dark mode in Preferences.

Security

Zero-retention routing for client data

Every model call that carries client data is routed only to providers that keep nothing. Statement extraction also has a backup model if the first one is unavailable.
